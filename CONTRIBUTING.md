# Contributing verification evidence

This repository welcomes attempted reproductions, counterexamples, citation corrections and scope objections. Please open a GitHub issue and distinguish clearly among:

- replay of the released commands in a new environment;
- independent reimplementation or clean-room reproduction;
- mathematical review of a stated proposition;
- formalisation in a proof assistant;
- literature or novelty evidence; and
- field or operational validation.

A useful report identifies the release tag and commit, operating system, Python version, exact command, observed output, and hashes of any changed inputs. Attach the smallest reproducible instance for a suspected computational defect. Do not report a local replay as independent reproduction, or a passing verifier as proof of novelty or field validity.
